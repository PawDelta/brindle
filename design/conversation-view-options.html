conversation view · 4 directions

The same session, read four ways

A read-only Conversation tab beside the Terminal tab, rendering the CLI's own transcript as messages, tool calls, diffs, approval cards and cost (the plan's option A in design/api-key-ui-plan.html). Every direction below shows one real session: a bugfix with two edits, a test run that fails, a second edit, the run that passes, and a push held by a rule. Each shows a collapsed and an expanded tool call, a two-file diff, the failed command, the pending Allow/Deny card, the cost, and how the tab relates to the Terminal tab. Use 1–4 or the cards; T flips to the Terminal tab and back. Tool blocks open and close on click.

The frame is design-v3's; buttons wear the Tinted scheme the app ships. "Both" in the theme switch stacks a dark and a light window.

Where each direction puts the required pieces the row for the chosen direction is highlighted

Names and data. The tab is called Conversation, never after the CLI, and it doesn't copy the TUI's look (design/chat-view-tos.html, flag 3). The header says the session is signed in with an API key and nothing more: no variable names, no key fragments, no account identifiers. Tool output passes through the daemon's mask before it reaches the view.
