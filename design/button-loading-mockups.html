Button loading states

Click any button: it enters the loading state for ~2s, ignores further clicks, then returns. Tokens match the app (hairline button, mono green main button). Reduced motion swaps animation for static cues.

1. Spinner replaces the icon

Label never moves; the leading icon turns into a small spinner, so the button keeps its exact width.

2. Label becomes “Starting…”

Plain words do the work: the label says what is happening, with three softly pulsing dots and no layout jump.

3. Shimmer along the bottom edge

The button looks untouched; a thin light runs along its lower edge. Quietest option, works for any label.

4. Dim + spinner after a 300ms delay

Fast actions never flicker: nothing changes until 300ms in. Try “Quick” (200ms, no visible change) next to the slow one.
