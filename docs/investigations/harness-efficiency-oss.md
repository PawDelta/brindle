# Open-source coding-agent harness efficiency

Evidence checked 2026-11-13. Percentages below are **estimates** of total API spend on brindle's measured Fable 5.2 session, not additive guarantees. Brindle's measured baseline: reviewer 34%, supervisor 26%, redoing work 25%; each agent start writes 60–190k cached tokens; on large tasks the file-overlap guard can prevent all parallel work. Savings need an instrumented A/B benchmark before becoming targets.

## 1. Scope parallel work and keep handoffs small

**Practice.** Claude Code gives subagents fresh, isolated contexts; OpenHands and Goose also support delegated specialists. Roo Code's Boomerang orchestrator splits complex work into scoped subtasks and returns concise summaries, keeping execution detail out of the parent context. MetaGPT assigns software-company roles and standardizes handoffs through intermediate artifacts such as requirements and design documents. CrewAI supports sequential or hierarchical assignment; AutoGen supports bounded agent conversations. These patterns help when independent investigations or file-disjoint edits can run concurrently, while duplicate context and manager chatter can erase savings. Aider's architect/editor split is sequential. [Claude Code session management](https://claude.com/resources/articles/using-claude-code-session-management-and-1m-context), [Goose subagents](https://goose.vcorp.ai/docs/guides/context-engineering/subagents/), [Roo Boomerang Tasks](https://github.com/shaneholloman/roo-code-docs/blob/main/docs/features/boomerang-tasks.mdx), [MetaGPT paper](https://arxiv.org/abs/2308.00352), [CrewAI process](https://github.com/crewAIInc/crewAI/blob/main/docs/v1.15.0/en/learn/hierarchical-process.mdx), [AutoGen termination](https://microsoft.github.io/autogen/stable/user-guide/agentchat-user-guide/tutorial/termination.html), [Aider modes](https://aider.chat/docs/usage/modes.html).

**Brindle mapping and estimate.** A dependency-aware, file-disjoint decomposition can release parallelism currently lost to the overlap guard and reduce supervisor waiting/replanning. Requiring compact, artifact-based handoffs should reduce reviewer and supervisor re-reading. Estimate **5–15% total spend saved**, mainly supervisor (up to 5 percentage points) and redo (up to 3); parallelism may improve elapsed time more than token cost. This assumes only tasks with independent files are parallelized and no redundant scout agents.

## 2. Route by task difficulty; use a cheap first pass

**Practice.** Agentless uses a deterministic localization → repair → validation pipeline, narrowing what the model must decide. mini-SWE-agent is a small bash-only loop with configurable cost limits; its leaderboard publishes per-instance results. SWE-agent's paper reports that richer search can exhaust both budget and context. Aider's architect mode lets a reasoning model propose a plan while an editor model applies it. [Agentless paper](https://arxiv.org/abs/2407.01489), [mini-SWE-agent](https://github.com/SWE-agent/mini-swe-agent), [SWE-agent paper](https://proceedings.neurips.cc/paper_files/paper/2024/file/5a7c947568c1b1328ccc5230172e1e7c-Paper-Conference.pdf), [Aider architect/editor](https://aider.chat/2024/09/26/architect.html).

**Published figures.** Agentless reports **32% (96/300), $0.70 average per issue** on SWE-bench Lite. In the 2024 OpenHands paper, CodeActAgent v1.8 with claude-3-5-sonnet@20240620 reports **26% and $1.10 average cost per instance** on the same 300-instance Lite benchmark without hints. The SWE-agent paper reports GPT-4 Turbo at **18% and $1.67 average cost per Lite instance**. These are separate implementations/model setups; dollars are API cost per benchmark instance, not per resolved task. [OpenHands Table 3](https://arxiv.org/html/2407.16741v3), [SWE-agent Table 1](https://proceedings.neurips.cc/paper_files/paper/2024/file/5a7c947568c1b1328ccc5230172e1e7c-Paper-Conference.pdf), [Agentless](https://arxiv.org/abs/2407.01489).

mini-SWE-agent's public SWE-bench leaderboard reports average cost per instance by model and harness version. One dated 2025-11-24 entry reports Claude Sonnet 4.5 (medium), mini-SWE-agent 1.16.0, **74.4% and $0.72/instance** on SWE-bench Verified (500 instances). [Leaderboard](https://www.swebench.com/). No comparable per-task dollar, token, or wall-time measurement was found in the cited Aider, Cline/Roo, Goose, Claude Code, Codex CLI, AutoGen, CrewAI, or LangGraph materials; MetaGPT reports costs on a different SoftwareDev benchmark, so do not compare it as SWE-bench evidence. These are published measurements, not brindle savings.

**Brindle mapping and estimate.** Route mechanical review, file discovery, and test planning to a cheaper model; escalate only uncertain/high-impact work. Agentless-style localization before dispatch may avoid unnecessary supervisor turns. Estimate **5–12% total**, mostly reviewer/supervisor lines (combined 60% of baseline); downside is missed issues that cause more redo.

## 3. Minimize repeated context; preserve cacheable prefixes

**Practice.** Anthropic describes Claude Code's stable prompt prefix and cache-preserving system reminders. Claude Code also compacts older conversation into a summary when context grows, or on `/compact`; this trades some detail for room and can avoid carrying a bloated transcript. Codex likewise compacts history into a smaller representative conversation. Goose enables Anthropic prompt caching on supported providers. Cline documents provider caching and task history; Aider's repo map gives compact, relevant symbols instead of dumping a repository. [Claude prompt-cache design](https://claude.com/blog/lessons-from-building-claude-code-prompt-caching-is-everything), [Claude session and compaction guide](https://claude.com/resources/articles/using-claude-code-session-management-and-1m-context), [Codex agent loop](https://openai.com/index/unrolling-the-codex-agent-loop/), [Goose providers](https://goose.vcorp.ai/docs/getting-started/providers/), [Cline task management](https://docs.cline.bot/core-workflows/task-management), [Aider repository map](https://aider.chat/docs/repomap.html).

**Brindle mapping and estimate.** The 60–190k-token cache writes per agent start are directly addressable: reuse stable prompt prefixes, avoid changing tool/system definitions between turns, carry forward a concise task packet, and avoid restarting reviewer agents when resumable context suffices. Estimate **8–20% total** if cache writes are billed/material and repeated agent starts are common; estimate is capped by the unknown share of total bill attributable to cache writes. Context retrieval and compaction can also lower supervisor and reviewer input, but must retain decisions, changed files, and test evidence.

## 4. Verify once, early, and against the actual change

**Practice.** Agentless validates candidate patches with reproduction and regression tests. SWE-agent's paper describes how poor search behavior can spend budget without benefit. Cline checkpoints every tool action so a mistaken edit can be reverted; LangGraph persists completed node writes so recovery does not repeat successful work. [Agentless paper](https://arxiv.org/abs/2407.01489), [SWE-agent paper](https://proceedings.neurips.cc/paper_files/paper/2024/file/5a7c947568c1b1328ccc5230172e1e7c-Paper-Conference.pdf), [Cline checkpoints](https://github.com/cline/cline/blob/main/docs/core-workflows/checkpoints.mdx), [LangGraph persistence](https://github.com/langchain-ai/langgraphjs/blob/main/docs/docs/concepts/persistence.md).

**Brindle mapping and estimate.** A reviewer should inspect the diff and relevant test evidence, then return actionable findings; avoid serial review rounds that rediscover the same issue. Run focused verification before broad review and preserve successful work when a later step fails. Estimate **4–10% total**, concentrated in redo (25% baseline) and reviewer (34%): roughly 2–6 points of redo plus 1–3 reviewer points. The range assumes failures are detectable with focused checks and recovery avoids redoing the whole session.

## 5. Bound loops and recover from checkpoints

**Practice.** mini-SWE-agent exposes a cost limit; AutoGen has maximum-turn and message-count termination; CrewAI has iteration/request limits. Cline can resume an interrupted task and restore file/task checkpoints. LangGraph checkpoints completed graph work and resumes after node failure. These mechanisms constrain runaway use while preserving useful progress. [mini-SWE-agent benchmark options](https://mini-swe-agent.com/latest/usage/swebench/), [AutoGen termination](https://microsoft.github.io/autogen/stable/user-guide/agentchat-user-guide/tutorial/termination.html), [CrewAI hierarchical process](https://github.com/crewAIInc/crewAI/blob/main/docs/v1.15.0/en/learn/hierarchical-process.mdx), [Cline task management](https://docs.cline.bot/core-workflows/task-management), [LangGraph persistence](https://github.com/langchain-ai/langgraphjs/blob/main/docs/docs/concepts/persistence.md).

**Brindle mapping and estimate.** Apply per-role token/turn budgets, stop repeated low-information tool cycles, and resume from successful work rather than restarting. Estimate **3–8% total**, mainly preventing tail costs in supervisor and redo. This overlaps with verification and routing; do not sum ranges mechanically.

## 6. Interpret numbers cautiously

Published task costs vary with benchmark, model, cache accounting, sampling, and harness version. OpenHands, Agentless, SWE-agent, and mini-SWE-agent figures above all specify their benchmark denominators and representative model/setup. MetaGPT's 2024 SoftwareDev paper provides a non-comparable example: on GPT-4, 70-task average prompt/completion tokens are reported with per-task elapsed seconds and money costs; its appendix's 10 displayed task rows show approximately **22–33k prompt tokens, 6.2–6.7k completion tokens, 553–582 seconds, and $1.04–$1.35**. This is an average over generated software projects, not issue repair. [MetaGPT Table 9](https://proceedings.iclr.cc/paper_files/paper/2024/file/6507b115562bb0a305f1958ccc87355a-Paper-Conference.pdf). These measurements demonstrate why cost figures should not be ranked across unlike tasks.

Across these techniques, a plausible **combined estimate is 15–30% of total spend**, below the sum of individual ranges because effects overlap. The largest measurable opportunities are avoiding redundant cache writes and eliminating rework; parallelism should be judged separately on wall-clock time and completed-task cost.
