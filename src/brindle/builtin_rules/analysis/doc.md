description: Leave an analysis doc for large work
---
This is large work: before you report, write a short analysis doc in Markdown,
in whatever shape serves the work best. Cover what was built, the decisions
made and the alternatives rejected, how it was verified and what wasn't, known
gaps, and follow-ups. Write it in the docs folder named below, never inside the
repo, and don't commit it.
